# Sample lecture

`faraday_candle_lecture1.txt` is the opening of Lecture I of Michael Faraday's
*The Chemical History of a Candle*. Faraday gave these lectures to young people at the
Royal Institution in London in 1860–61. The text is in the public domain.

Source: Project Gutenberg eBook #14474 (https://www.gutenberg.org/ebooks/14474).
Only the lecture text is used: the first four paragraphs, with line wrapping, footnote
markers and italics marks removed.

Try it:

```bash
uv run lecture-summarizer summarize samples/faraday_candle_lecture1.txt
```
